# FFI oneof cases that Livekit.Rtc.Dotnet intentionally does NOT use.
# One key per line: FfiRequest/<Case>, FfiEvent/<Case> or RoomEvent/<Case>, using the C# case
# name that ffi_coverage.py prints. '*' is a wildcard. Always add a reason, so the next
# /sync-rust-sdks run knows why.
#
# Candidates found on livekit-ffi/v0.13.3 (after the November 2026 parity work: data tracks,
# encoded video, remote publication controls and the participant events are implemented), grouped
# by the reason they would be ignored for. All commented out: uncomment what the maintainer decides
# to skip; everything that stays commented keeps showing up as "unused".
