Types the Twirp code generator emits outside any namespace: the [exception](xref:Global.Twirp.Exception) and [error codes](xref:Global.Twirp.ErrorCode) that [TwirpException](xref:Livekit.Server.Sdk.Dotnet.TwirpException) builds on, and the generated `Twirp` client, kept for code that calls it directly. The service clients do not use it.
